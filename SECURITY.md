# Segurança

Não abra uma issue pública para relatar uma vulnerabilidade ou possível exposição de dados. Use o recurso **Report a vulnerability** do GitHub quando estiver disponível no repositório.

Este projeto não requer credenciais nem variáveis de ambiente. Se uma contribuição introduzir um serviço externo, documente apenas nomes de variáveis em `.env.example`; nunca versione tokens ou valores reais.
